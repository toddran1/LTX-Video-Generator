# Source Workflows

Put editable ComfyUI workflow JSON files here.

These are the normal ComfyUI editor exports with a top-level `nodes` array. They are useful for visual editing in ComfyUI, but the Runpod app cannot queue them directly.

Current source target:

```text
runpod/workflows/source/LTX-2.3_-_V2V_ReTake_recreate_any_section_of_any_video.json
```

After editing a source workflow in ComfyUI, export it as API JSON and save the API export under `runpod/workflows/api/`.
